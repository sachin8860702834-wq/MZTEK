# NotebookLM Exports

This folder contains clean, curated documents meant to be easy for NotebookLM
to ingest from GitHub.

The goal is to give NotebookLM one or a few high-signal sources instead of
forcing it to infer product direction from many scattered files.

## Current Primary Source

- `mztek-source-of-truth.md`

## Export Rule

Keep these files:
- concise
- structured
- high signal
- updated as the product direction changes
