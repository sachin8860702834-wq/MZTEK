# MZTEK MVP Scope

## MVP Outcome
Provide a local-first project governance layer that can document a software build, track progress, and flag unsupported completion claims.

## In Scope
- Project notebook structure
- Decision log structure
- Progress and blocker tracking
- Task ownership/status model
- Zero-trust completion checks
- Reusable documentation-first workflow

## Out of Scope
- Full IDE integration
- Full multi-agent runtime
- Cloud/local model routing
- Dashboard UI implementation
- Automatic code execution adapters

## MVP Principles
- Plan broadly, build incrementally
- Trust nothing without proof
- Document as you build
- Reuse bricks across projects

## MVP Deliverables
- A stable document schema for project memory
- A stable board/status schema for work tracking
- A first-pass validation checklist for fake "done" detection
- A documented implementation sequence for the next build loop
