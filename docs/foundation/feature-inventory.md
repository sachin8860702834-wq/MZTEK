# MZTEK Master Feature Inventory

## 1. Product Brain

### Goal
Convert rough product ideas into structured, buildable plans.

### Features
- Idea capture and clarification
- Comparable product and competitor discovery
- wedge and differentiation guidance
- MVP discipline guidance
- Problem, user, and goal definition
- MVP boundary definition
- Product brief generation
- Requirements extraction
- User flow generation
- Milestone generation
- Feature decomposition
- Build-order recommendations
- Product readiness classification

## 2. Project Notebook and Memory

### Goal
Create a NotebookLM-like grounded memory layer for every product build.

### Features
- Persistent project brief
- Decision log
- Architecture notes
- Progress summaries
- Blocker log
- Validation history
- Conversation summaries
- Lessons learned
- Reusable pattern library
- Resume-from-context support

## 3. Task and Work Graph

### Goal
Track what is being built, by whom, and what is pending on what.

### Features
- Task hierarchy
- Subtasks and dependencies
- Status engine
- Ownership assignment
- Blocker tracking
- Evidence tracking
- Handoff records
- Activity timeline
- Task board and dependency graph

## 4. Zero-Trust Validator

### Goal
Catch fake completion, weak claims, and missing proof.

### Features
- Claim versus evidence checker
- Fake "done" detection
- Dependency existence checks
- Validation presence checks
- Missing-proof warnings
- Status downgrade engine
- Contradiction detection
- Assumption surfacing
- Route/API/env verification

## 5. Benchmark Engine

### Goal
Measure every project against real software-building methods.

### Features
- Universal product benchmark
- Product-type benchmark packs
- Planning benchmark checks
- Architecture benchmark checks
- Build benchmark checks
- Validation benchmark checks
- Release benchmark checks
- Security benchmark checks
- Readiness scoring

## 6. Security and QA System

### Goal
Enforce security-first and product-quality-first execution.

### Features
- API validation checklist
- Auth and authz review
- Input validation checks
- Secret handling checks
- Abuse-path thinking
- QA reviewer agent
- Security reviewer agent
- Release gate
- Risk classification

## 7. Agent and Team Orchestration

### Goal
Replace shallow solo-agent behavior with structured team execution.

### Features
- Team topology engine
- Role templates
- Skill registry
- Skill-based agent creation
- Ownership rules
- Handoff protocol
- Shared memory model
- Fake multi-agent detection
- Escalation and review flow

## 8. Chat and Prompt Middleware

### Goal
Make MZTEK the default interface between user intent and execution tools.

### Features
- Builder chat interface
- Prompt enrichment
- Context injection
- Hidden system instruction layer
- Output normalization
- Tool-response auditing
- Next-step recommendation
- Prompt history and replay

## 9. IDE and Tool Integration

### Goal
Connect MZTEK to editors, agents, and execution tools without hard vendor lock.

### Features
- VS Code adapter
- Cursor adapter
- Windsurf adapter
- CLI adapter
- Tool evidence ingestion
- File/change tracking
- Background task hooks
- MCP-aware integration

## 10. Model Routing and Provider Layer

### Goal
Support local, cloud, and hybrid model execution intelligently.

### Features
- Provider registry
- Local/cloud routing policy
- Cost-aware routing
- Privacy-aware routing
- Escalation engine
- Lite-model first pass
- Strong-model escalation
- Token and budget tracking

## 11. Dashboard and Tracking UX

### Goal
Give users a clear picture of project state, communication, ownership, and risk.

### Features
- Project overview dashboard
- Agent activity panel
- Task ownership board
- Validation status view
- Blocker spotlight
- Conversation threads
- Decision timeline
- Dependency map
- Fake-completion alerts

## 12. Voice Companion

### Goal
Give users a natural spoken project companion grounded in real project state.

### Features
- Voice pulse summaries
- Spoken project updates
- Voice preference options
- Spoken answers to project-state questions
- Voice playback of blockers, next actions, and validation state

## 13. Learning Engine

### Goal
Turn failures and successes into future improvements.

### Features
- Failure taxonomy
- Lesson extraction
- Pattern extraction
- Check generation from failures
- Routing improvements
- Reusable workflow updates
- Cross-project knowledge reuse

## 14. Reusable Workflow Packs

### Goal
Provide ready-made product-building methods for common project types.

### Features
- SaaS MVP pack
- Auth app pack
- Dashboard pack
- Landing page plus waitlist pack
- Marketplace pack
- Internal tool pack
- AI app pack
- Release checklist pack
